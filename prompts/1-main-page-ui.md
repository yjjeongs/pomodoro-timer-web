뽀모도로 타이머 웹의 메인 페이지를 만들어줘

- 일단 HTML, CSS만 사용해서 UI만 구현해줘
- HTML 배치는
  - h1 태그로 "pomodoro" 제목을 표시
  - 현재 남은 시간 표시
  - 시작, 정기, 초기화 버튼 배치
  - 설정 버튼 배치
- 스타일을 위한 CSS 코드들은 index.css 파일에 보관

자바스크립트를 이용해서 메인페이지에 기능을 추가해줘

- 시작 버튼에 타이머를 시작하는 이벤트 핸들러를 설정
- 정지 버튼에 타이머를 정지하는 이벤트 핸들러를 설정
- 초기화 버튼에 타이머를 리셋하는 초기화 이벤트 핸들러를 설정
- 이벤트 핸들러들은 onclick 방식으로 설정
- 자바스크립트 코드들은 index.js 파일에 보관

설정 페이지를 새롭게 만들어줘

- 일단 HTML, CSS만 사용해서 UI만 구현해
- HTML 배치
  - h3 태그로 "Setting" 제목에 배치
  - 타이머 시간을 설정할 INPUT 하나 배치
  - 설정 완료 버튼을 배치
- CSS 코드들은 setting.css 파일에 보관
- 메인 페이지에서 설정 버튼을 클릭하면, 세팅페이지로 이동
  - 굳이 스타일은 설정하지마

설정 페이지의 기능을 구현해줘

- UI는 메인 페이지와 비슷한 형식으로 변경해줘
- 타이머 시간 변경 기능을 구현해줘
  - 1분 이상, 60분 이하로만 타이머 시간 변경 가능
  - 시간을 비워둔채로는 저장 버튼 클릭 불가
  - 바뀐 시간은 매인 페이지에 즉시 반영
  - 바뀐 시간은 새로 고침 유지 됨.
